# Super Mario Bros 3 - Custom Engine DX10 Edition
A fan-made remake of **Super Mario Bros 3** built from scratch with a custom game engine(ThS. Đinh Nguyễn Anh Dũng) using DirectX 10.

## Future
- Using a **custom game engine** powered by **DirectX 10**
- Smooth 2D platforming gameplay inspired by the NES classic
- Classic enemies: Little Goomba, Para Goomba, Red Para Goomba, Koopa Troopas, Koopa Paratroopas, Piranha Plants, Venus Fire Traps.
- Items: Coins, 1-Up Mushrooms(red/green), Koopa Shells, Cards
- Power-up: Super Leaf, Super Mushroom.
- Objects: ? Block, Brick, Cloud Block, Empty Block, Mega ? Block, Switch Block, Wood Block
- Pipes: Giant pipe, Warp Pipe
- Other objects: Goal
- Keyboard support

## 🛠️ Build Instructions
> 💡 Requirements: Windows, Visual Studio 2022, DirectX SDK (June 2010), `nlohmann::json`
### 📦 System Requirements

- OS: Windows 10 or later
- Compiler: Visual Studio 2022
- DirectX SDK: [June 2010 version](https://www.microsoft.com/en-us/download/details.aspx?id=6812)
- Optional: CMake (if you use it)
- JSON Library: [`nlohmann/json`](https://github.com/nlohmann/json)
